### Основні поняття 📚

**Assert** – швидка перевірка умов, кидає `AssertionError` при провалі 🚨  
**Юніт-тести** – тестування маленьких шматочків коду окремо від усього іншого ⚙️  
**Unittest** – вбудована, класна, трохи бюрократична 🏛️  
**Pytest** – сучасна, мінімалістична, улюблениця спільноти 🌟  
**Coverage** – показує, скільки коду реально «пробігли» тести 📈  
**Mocking** – підміна реальних функцій, щоб тести були ізольовані 🎭

### Порівняння Unittest vs Pytest ⚔️

| Характеристика         | Unittest                          | Pytest                              |
|-----------------------|-----------------------------------|-------------------------------------|
| Синтаксис             | Класи + спадкування `TestCase`    | Звичайні функції 😌                 |
| Утвердження           | `self.assertEqual()`…             | Просто `assert` ❤️                  |
| Фікстури              | `setUp()` / `tearDown()`          | `@pytest.fixture` ✨                 |
| Запуск                | `python -m unittest`              | `pytest` (і все) 🚀                 |
| Складність            | Формально, багато коду            | Легко і швидко                      |
| Популярність          | Класика, завжди під рукою         | Вибір більшості сучасних проектів   |

```bash
